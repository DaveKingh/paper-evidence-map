# FreshScope: Current-Session Document Routing

## Abstract

FreshScope improves over BaseMap on Dataset N. The paper claims a 9-point gain.

## Method

FreshScope uses a two-stage router: document-type detection followed by label selection.

## Results

| System | Dataset N macro-F1 |
|---|---:|
| BaseMap | 0.70 |
| FreshScope | 0.79 |

## Conclusion

FreshScope gains 9 percentage points on the single tested dataset. Repeated runs, external datasets, and compute cost are not reported.
