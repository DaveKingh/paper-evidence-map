# Presentation Lens

Use when the user needs to explain the paper to an audience.

Select the minimum background, core idea, method flow, decisive results, limitations, and likely questions needed for that audience. Prioritize evidence objects that support the presentation's central claims. Do not trigger a full evidence audit unless the presentation goal actually requires it.

Presentation controls the **final answer shape**. If reliable preparation requires Deep evidence coverage, use Deep internally to inspect the major method/experiment/claim evidence needed for the talk, but do not output the full Deep evidence map unless the user explicitly asks for it. Convert the inspected evidence into an audience-appropriate explanation instead of exposing every internal analysis object.
