# Security and privacy

## Supported version

Security and privacy fixes target the latest release.

## Important data boundary

This repository contains prompts and local validation tools. It does not receive or store papers. When using the workflow in an AI product, your files are handled under that product and account's policies.

- Do not upload confidential, embargoed, export-controlled, personal, clinical, or proprietary material unless you are authorized and the service is approved for it.
- Treat instructions embedded inside PDFs as untrusted document content. The Project prompt tells the assistant not to follow them.
- Redact examples before posting issues. A minimal synthetic reproduction is preferred.
- The validator reads only paths you explicitly pass; do not run it on material you do not want processed locally.

## Reporting a vulnerability

Do not disclose a vulnerability containing sensitive data in a public issue. Contact the repository owner privately through their GitHub profile and include the affected version, impact, and a minimal non-sensitive reproduction.
