# Paper Evidence Map v0.1.0 — reproducible first release

The first public release turns an evidence-first paper-reading prompt into a testable workflow.

## Included

- Paste-ready English and Simplified Chinese ChatGPT Project instructions.
- `Round 1` evidence mapping and `Round 2` skeptical audit.
- Focused question, reading-status, paper-comparison, and JSON export triggers.
- A synthetic mini-paper with planted overclaims and missing evidence.
- Public expected findings, a 100-point rubric, and representative output.
- A zero-dependency validator and GitHub Actions check.
- Bilingual quickstarts, methodology, FAQ, contribution, security, and launch docs.

## Known limitations

- Model outputs vary across runs and product modes.
- The automated checker validates structure, not scientific truth.
- Complex or scanned PDFs may be incompletely accessible.
- Field-wide novelty requires external literature review.

## Try it

Paste the Project instructions, upload `examples/synthetic/paper.md`, send `Round 1`, and compare the result with `examples/synthetic/expected-findings.md`.
