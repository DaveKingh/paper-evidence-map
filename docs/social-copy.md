## GitHub release / general post

I built Paper Evidence Map because paper summaries often preserve the authors' confidence while dropping the evidence boundaries.

Add one prompt to a ChatGPT Project, upload a PDF, and type “Round 1.” It maps each major claim to Methods, experiments, figures, tables, missing details, and the strongest conclusion the evidence can actually support.

The repository includes a synthetic paper with planted contradictions, public expected findings, a 100-point rubric, and a zero-dependency checker—so you can test it instead of trusting a polished demo.

Try the challenge and report what it misses: https://github.com/YOUR_USERNAME/paper-evidence-map
