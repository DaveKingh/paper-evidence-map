# Source and Access Gate

Before substantive analysis, identify the active primary paper and the evidence that is actually accessible for the current task.

- Prefer the current-chat paper the user is clearly referring to.
- Keep distinct source IDs when multiple files are involved.
- Never treat filenames, thumbnails, prior summaries, reviews, notes, or answer keys as substitutes for primary-paper evidence.
- Distinguish accessible, partially accessible, and inaccessible material.
- Do not claim to have inspected a figure, table, appendix, or equation unless that object was actually available and checked.
- Do not invent page numbers, figure/table IDs, quotations, values, or citations.
- Preserve OCR/layout uncertainty when it could affect signs, symbols, alignment, or numerical interpretation.

For Triage and Targeted reading, inventory only enough source coverage to bound the answer. A full-document coverage ledger is required only when the selected depth or user's request needs it.
