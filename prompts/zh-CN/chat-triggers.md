# 中文触发词速查

将 `project-instructions.md`（完整功能）或 `project-instructions-compact.md`（较短的两轮核心版）放进 ChatGPT Project instructions。每篇论文新开一个聊天，上传论文并等待附件可用，再发送以下短指令。

```text
第一轮
```

## 严格复核

```text

```

## 聚焦一个问题

```text
聚焦：作者关于跨数据集泛化的结论，证据到底支持到什么程度？
```

## 查看覆盖范围

```text
阅读状态
```

## 机器可读导出

```text
导出 JSON
```

JSON 导出属于完整版。完整提示词已经内嵌字段契约，模型不必能看到仓库里的 schema；需要机器校验时，最好再上传 `schemas/evidence-map.schema.json`。

## 核对一个定位

```text
核对定位：C3
```

## 外部新颖性核查

```text
新颖性核查。请把论文内部声称与外部发现分开，并报告检索日期、来源、检索式、最接近工作和覆盖限制。
```

## 对比论文

```text
对比论文：只比较它们对同一研究问题的假设、数据、指标、关键证据和结论边界。先分别建图，再比较。
```

若论文没有成功附加或无法读取，不要要求模型“凭印象继续”。请重新上传、提供 OCR，或粘贴决定性段落。没有原始内容时，正确的“访问限制”回答优于看似完整的证据地图。
